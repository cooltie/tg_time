# Быстрый старт TG Timer

## 🚀 За 5 минут

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка бота
Отредактируйте `env.py`:
- Замените `API_TOKEN` на ваш токен от @BotFather
- Укажите данные вашей PostgreSQL базы

### 3. Запуск
```bash
python timetracking.py
```

### 4. Использование
1. Найдите бота в Telegram
2. Отправьте `/start`
3. Следуйте инструкциям

## 📱 Основные команды

- **`/start`** - запуск бота
- **"Стоп"** - остановка таймера
- **"Новый проект"** - создание проекта

## ⚠️ Важно

- Убедитесь, что PostgreSQL запущен
- Проверьте доступность базы данных
- Токен бота должен быть действительным

## 🔧 Docker (альтернатива)

```bash
docker compose up --build
```

## 📞 Проблемы?

1. Проверьте логи в консоли
2. Убедитесь в корректности настроек БД
3. Запустите тесты: `pytest test_timetracking.py`
