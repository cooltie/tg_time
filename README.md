# TG Timer - Telegram бот для учета времени

## Описание проекта

TG Timer - это Telegram бот для отслеживания времени, потраченного на различные проекты. Бот позволяет пользователям запускать таймеры, останавливать их и сохранять информацию о затраченном времени с комментариями.

## Основные функции

### 🚀 Запуск и настройка
- **`/start`** - команда для начала работы с ботом
- Автоматическое создание новых проектов
- Выбор существующих проектов из списка

### ⏱️ Управление таймером
- **Запуск таймера** - автоматически при выборе проекта
- **Остановка таймера** - кнопка "Стоп" для завершения сессии
- **Автоматический расчет** времени работы

### 📝 Учет времени
- Сохранение времени начала и окончания работы
- Расчет продолжительности сессии
- Добавление комментариев к каждой сессии
- Форматирование времени в формате ЧЧ:ММ

### 💾 Хранение данных
- Автоматическое создание пользователей в базе данных
- Сохранение проектов и сессий в PostgreSQL
- Связь проектов с пользователями

## Принцип работы

### 1. Инициализация
При первом запуске бот:
- Создает таблицы `users` и `projects` в базе данных
- Регистрирует пользователя по Telegram ID
- Предлагает создать первый проект

### 2. Рабочий процесс
```
Запуск (/start) → Выбор проекта → Запуск таймера → Работа → Остановка → Комментарий → Сохранение
```

### 3. Состояния пользователя
- `awaiting_new_project` - ожидание названия нового проекта
- `selecting_project` - выбор существующего проекта
- `running` - таймер запущен
- `awaiting_comment` - ожидание комментария после остановки

### 4. Структура базы данных
- **users**: ID пользователя, Telegram ID, дата создания
- **projects**: ID проекта, ID пользователя, название, время начала/окончания, продолжительность, комментарий

## Технические требования

### Зависимости
- Python 3.7+
- aiogram (Telegram Bot API)
- asyncpg (PostgreSQL драйвер)
- pytest (для тестирования)

### Конфигурация
- Telegram Bot Token
- PostgreSQL база данных (Railway)
- Настройки подключения в `env.py`

## Установка и запуск

### Локальная установка
```bash
# Клонирование репозитория
git clone <repository-url>
cd TG_timer

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
# Отредактируйте env.py с вашими данными

# Запуск бота
python timetracking.py
```

### Docker запуск
```bash
# Сборка и запуск
docker compose up --build

# Приложение будет доступно на http://localhost:5432
```

## Использование

### Первый запуск
1. Отправьте `/start` боту
2. Введите название первого проекта
3. Таймер автоматически запустится

### Рабочий процесс
1. **Выбор проекта**: существующий или "Новый проект"
2. **Работа**: таймер отсчитывает время
3. **Остановка**: нажмите кнопку "Стоп"
4. **Комментарий**: добавьте описание выполненной работы
5. **Повтор**: выберите следующий проект

### Управление проектами
- Автоматическое создание новых проектов
- Сохранение истории всех сессий
- Возможность работы с несколькими проектами

## Тестирование

Проект включает тесты для проверки функциональности:
- `test_timetracking.py` - основные тесты
- `test_timetracking_simple.py` - простые тесты
- `test_timetracking_full.py` - полные тесты

Запуск тестов:
```bash
pytest test_timetracking.py
```

## Архитектура

- **Асинхронная обработка** - использование asyncio для эффективной работы
- **Состояния пользователей** - управление через словарь `user_timers`
- **База данных** - PostgreSQL с автоматическим созданием схемы
- **Telegram Bot API** - интеграция через aiogram

## Безопасность

- Хранение конфиденциальных данных в отдельном файле `env.py`
- Валидация пользовательского ввода
- Изоляция данных пользователей
